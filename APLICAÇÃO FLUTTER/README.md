# Questão 3 

## Aplicação Flutter - Cores de Fundo

Aplicação desenvolvida em Flutter com quadrados coloridos na tela.

Ao clicar em um dos quadrados, a cor de fundo da tela é alterada para a cor selecionada.

## Funcionalidades

* Exibição de 8 quadrados coloridos;
* Clique/toque para selecionar uma cor;
* Alteração da cor de fundo;
* Ajuste automático da cor do texto para manter o contraste;
* Destaque visual da cor selecionada.

## Arquivo principal

O código da aplicação está no arquivo `main.dart`.
